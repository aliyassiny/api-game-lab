# Documentacion del Repositorio

Este repositorio contiene el informe, documentación técnica, scripts de pruebas y parches aplicados al proyecto **Damn Vulnerable RESTaurant API Game**, como parte del análisis de seguridad en APIs REST.

## Contenido
- `docs/` → Informe final, documentación técnica y capturas.
- `scripts/` → Scripts y colecciones de pruebas (Postman, PowerShell, Bash).
- `patches/` → Código con parches aplicados a vulnerabilidades.
- `extension/` → Nuevo nivel agregado al juego (endpoint y pruebas).
